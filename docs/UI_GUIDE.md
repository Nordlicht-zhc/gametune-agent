# GameTune 界面使用指南

GameTune 帮你把设置变化与实际测量对应起来。它不会代替你修改游戏设置，也不会仅凭硬件型号、低 GPU 占用或 AI 描述宣布收益。

## 第一次使用

启动后点击“新建调校”，或使用左侧顶部的同名按钮。先填写电脑配置、游戏设置、测试场景和目标；不清楚的选项如实选择“未确认”或“不确定”。预填值只是输入起点，请按实际设备与游戏设置核对。

点击“记录环境并进入基线测试”后再采集数据。同一场景和设置先测 2 次，每次至少 60 秒。填写平均 FPS、1% Low 与已采集的 GPU 占用；两次结果波动超过 5% 时补测第 3 次。确认数据来自实际测试并保存，才能开始分析。

## 页面与操作

| 页面 | 先看什么 | 下一步 |
| --- | --- | --- |
| 当前调校 | 逐次测试表现、本次调整与测试条件 | 按建议打开当前实验，或展开分析依据 |
| 新建调校 | 设备、目标、游戏内当前设置 | 记录环境，再测基线 |
| 当前实验 | 本轮目的、指定设置、复测要求 | 核对实际执行情况，补充信息或保存结果 |
| 测试记录 | 执行状态、测量结果、评估 | 比较条件一致的记录，或打开旧任务 |
| 配置与报告 | 已验证配置及其比较基准 | 依据实测结果保留配置 |
| 模型设置 | 是否需要 AI 帮助解释或选建议 | 可选填写接口并测试连接 |

点击左侧底部的“使用说明”，可在应用内查看操作要点。

“当前调校”是任务总览，下面缩进的“执行本轮实验”属于该任务，用来执行计划、补测和确认恢复；实验页顶部可返回总览。“测试记录”和“配置与报告”用于回看过程与结果，不是每轮都要依次打开的步骤。评估后，尚需操作时回到实验页，任务结束时进入报告。

## 怎么做一次可靠的实验

保持采集工具、测试场景和时长一致，画质可以按偏好同时调整多项。多项变化将按整组实际配置记录，并从这组配置重新生成建议，不要求先完成旧建议。诊断测试用来区分原因，优化验证用来判断收益；两者不应混为一谈。补充设置和选择后续验证目标的步骤不要求采集帧率。

可以导入 CSV，也可以手动填写实测值。一个逐帧采集文件算一次运行，不把帧数当成重复次数。核对测试条件，并在实际执行之后勾选确认；确认框不是自动应用设置的按钮。

优化候选先测 1 次筛选，明显退步时按提示回滚；没有明显退步时继续累计到 3 次有效运行，再确认收益。诊断参考可能要求额外复测，以当前实验页的要求为准。测试条件改变时如实填写，程序会检查结果是否可比较。

限帧排查需要至少 2 次同配置测试，以便保存独立的不限帧参考。逐次手填时，每次的“测试次数”填 1，程序会累计；填写多次汇总时，次数指本次汇总包含的运行数。数据有效与设置有收益是两个判断：没有提升也可以是有效诊断，不要求每次平均 FPS 都提高 5%。分辨率对比的模糊区间复测规则只用于分辨率诊断。诊断达到重试上限并确认恢复后，本任务不再自动发出相同诊断；无效记录仍不参与瓶颈判断或收益评估。

出现“恢复上一组配置”的提示时，先在游戏中按恢复步骤改回，再点击确认。限帧诊断中，不限帧测试结果不能直接代表恢复限帧后的表现；报告会注明比较条件。

## 怎么读结果

复测页始终显示实际画面设置，可以同时记录阴影、抗锯齿、贴图等多项改动。只改画质时，测试条件仍可保持“与基线一致”；仅在场景、路线、供电或采集方式等变化时选择“有变化，需要说明”。保存后以实际采用配置继续规划，原建议不再作为必须完成的任务。整组表现可以比较，但不将变化拆分为单项设置的收益；当前采用配置与最佳已验证配置分别保存，测试不足、波动较大或条件改变的结果不会被当作已验证收益。

平均 FPS 反映整体流畅度。1% Low 由慢帧计算，帮助观察卡顿与帧率稳定性；不同采集工具的口径可能不同，应保持同一种工具。GPU 占用是辅助证据，低占用不能单独证明 CPU 瓶颈。

“建议”表示待执行计划，“已执行”表示你确认了实际设置，“已验证”表示有效且可比较的测试已达到要求。报告未获得比较依据时显示“待验证”，不代表改善为零。当前调校页的柱状图只展示记录中保存的逐次平均 FPS 与 1% Low；没有逐次数据时显示说明，不从汇总值推算连续帧时间。分析依据、测试方法与有效标准可通过“展开分析依据”查看。

## 数据与模型

任务和测试记录保存在本机。模型连接可选；AI 只解释结果并在已校验候选中选择建议，不改写测量值或保留、回滚结论。模型连接失败时使用本地规则。保存模型配置时，密钥沿用 Windows 账户保护机制。

“当前实验”的选择来源会区分 AI 比较与本地规则，并显示选择依据和待验证假设。展开“查看候选与历史反馈”可核对有哪些合法候选、本次选中哪项、最近实验结论及待处理问题；模型调用时还显示耗时。展开与收起只影响显示，不会执行设置、提交测量或改变当前计划。只有一个合法候选时不调用模型，调用失败则明确回退。

## 视觉与操作约定

陶土色按钮是页面主要操作；浅色按钮是辅助操作。侧栏以浅暖色标示当前位置，提示区域会用文字说明需要核对的信息。窗口变窄时，调校页的测试条件移到操作区下方，表单也会切换为单列。带向下箭头的圆角输入框可以展开，有些还支持自定义输入。键盘 Tab 可移动焦点，方向键选择菜单项，Enter 确认，Esc 关闭菜单。
