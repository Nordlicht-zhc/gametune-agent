# 一键运行测试样例

在项目根目录双击 `run_scenarios.bat`，或运行 `python run_scenarios.py`。结束时显示每个样例的结果，全部通过显示 `OK`；完整报告保存到 `.qa/scenario-results.txt`，下次运行会覆盖。批处理会停留在结果窗口，便于查看错误。

这组样例使用人工构造的数据、临时 SQLite 数据库和离屏界面，不读取正式测试数据库、不加载已保存的模型配置、不调用真实模型接口，也不修改游戏设置。临时数据库运行后自动清理。这些数值仅用于验证程序行为，不能作为真实游戏性能或优化收益。

## 波动判定与适用范围

当前波动指标是同配置多次运行的 `(最大值 - 最小值) / 中位数 × 100%`，分别检查平均 FPS 和 1% Low；它不是单次运行中最高帧与最低帧的差，也不是标准差。任一指标超过 5% 会触发稳定性检查，恰好 5% 不算超限。基线两次超限时要求第三次，第三次后仍超限则提示排查条件并重新采集，不靠无限增加次数通过。

诊断与正式优化都有本轮重试上限，持久化恢复不会重置预算；无法确认的结果不更新最佳配置。只有手工汇总值和“测试次数”、没有逐次记录时，程序无法反推出真实波动。因此，自动稳定性检查需要逐次录入或导入包含逐次运行的数据；这些样例不代表所有异常都已覆盖。

## 其他运行方式

只运行十五个流程与边界样例：`python -m unittest tests.test_user_scenarios -v`。运行项目全套回归：`python -m unittest discover -s tests -v`。一键入口会自动将临时文件放在项目的 `.qa/` 下，适合系统临时目录权限受限的环境。

这组测试可以替代上述固定流程的重复录入和点击检查。真实游戏数据采集、接口服务可用性、原生 Windows 窗口的高 DPI 显示与实际使用感受仍需分别验证。
