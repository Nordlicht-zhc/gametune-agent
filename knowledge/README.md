# 性能参考知识

`cs2.json` 定义可以执行的游戏设置规则；`cs2_performance.json` 保存外部实测数值，两者用途不同。外部数据用于 AI 比较候选及最近一次用户改动，不参与本机指标、有效性、保留或回滚判定，也不生成规则之外的设置。这里只整理此前检索并核对的资料，没有新增真实游戏验证。

首批数据覆盖抗锯齿、全局阴影、粒子、模型 / 贴图、光影、环境光遮蔽、动态阴影、贴图过滤、HDR 和角色对比度，共 10 类设置。原始 FPS 保留在各档位中，程序只在原值和新值都有来源记录时计算 `(新值 FPS / 原值 FPS - 1) × 100%`；这是来源设备上的变化，不是对用户电脑的预测。缺失档位不插值，多项变化不相加。FSR 等缺少本次可用逐项数值的项目不填造数字。

数值来源为 [9Erza 自行发布的 CS2 测试](https://github.com/9Erza/CS2-Optimization-Guide)，选取其第 8 节表格中的事实数据。测试平台、时期、地图和采集工具随来源保存；`low_fps` 对应原表的 `1% Low Average`，不是 `P1 FPS`。该来源是单平台社区参考，不是跨设备结论。总方法说明与画质章节的基准描述不同，三线性过滤的文字与表格还存在不一致，因此只使用选定表格值，不纳入三线性异常结论，不采纳该作者的系统安全、延迟或通用最佳配置建议。

[ComputerBase 的 2024 年 CS2 测试](https://www.computerbase.de/artikel/gaming/counter-strike-2-benchmark-test.87904/)作为来源背景保留，因涉及组合画质与多平台条件，没有将其预设结果拆成单项百分比。后续可增加独立测试来源，分别保存条件，不对不同设备或版本的数据直接平均。参考库缺失或损坏时跳过它，原有本地规划继续运行。
